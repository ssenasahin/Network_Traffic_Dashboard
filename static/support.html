Platform Dokümantasyonu

AetherScan, ağ güvenliği testleri için tasarlanmış gerçek zamanlı bir tarama ve izleme platformudur. Python tabanlı asenkron bir backend ile modern bir web arayüzü bir araya getirilmiştir.

Backend

  • FastAPI — REST & WebSocket API
  • asyncio — Eşzamanlı port tarama motoru
  • psutil — Ağ arayüzü & bağlantı izleme
  • SQLite — Tarama geçmişi depolama
  • NVD API v2 — CVE zafiyet veritabanı

Frontend

  • Tailwind CSS — Modern kurumsal arayüz
  • Chart.js — Gerçek zamanlı grafikler
  • WebSocket — Canlı veri akışı
  • Hanken Grotesk — Profesyonel tipografi
  • Material Symbols — İkon seti
