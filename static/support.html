menu_book [DOC_02] PLATFORM DOKÜMANTASYONU

AETHER_SCAN, ağ güvenliği testleri için tasarlanmış gerçek zamanlı bir tarama ve izleme platformudur. Python tabanlı asenkron bir backend ile modern bir web arayüzü bir araya getirilmiştir.

BACKEND
  • FastAPI — REST & WebSocket API
  • asyncio — Eşzamanlı port tarama motoru
  • psutil — Ağ arayüzü & bağlantı izleme
  • SQLite — Tarama geçmişi depolama
  • NVD API v2 — CVE zafiyet veritabanı
FRONTEND
  • Tailwind CSS — Dark tema arayüz
  • Chart.js — Gerçek zamanlı grafikler
  • WebSocket — Canlı veri akışı
  • JetBrains Mono — Monospace tipografi
  • Material Symbols — İkon seti
